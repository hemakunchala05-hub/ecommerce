## Phase 0: Project Setup & Monorepo Foundation
- **What was built**: Initialized the monorepo folder structure, Docker Compose skeleton, API Gateway, and individual microservice boilerplates (User, Product, Cart, Order, Payment, Notification).
- **Key Takeaways**: Each service is its own isolated unit with its own dependencies, environment variables, and database connection. Services never import directly from other services; communication happens exclusively over network protocols (HTTP/REST or message queues).
